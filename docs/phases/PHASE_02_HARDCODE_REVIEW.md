## Method and active paths

Followed configured values from required arguments through Pydantic validation to frontend projection and actual process bindings. Reviewed generated schemas separately from application call paths.

The candidate scan uses ripgrep on owned Python/JS/TS/Rust/JSON/YAML source, excluding dependencies, target/dist/.next, generated schemas/types, icon binaries and caches. It searches URLs, loopback names, workstation paths, numeric timeout/page-size candidates and credential references. [Raw candidates](evidence-02/hardcode-scan.txt) and [line dispositions](evidence-02/hardcode-dispositions.json) preserve the method and every candidate. The scan returned 109 lines at this snapshot. The count is not a cleanliness proof; numeric/authority/UI call paths were also read manually.
